# 方塘像素體 16x16 | SqrPond 16x16

## ℹ️ 簡　介
 - 這是一款基於「[JF Dot Izumi Gothic](http://jikasei.me/font/jf-dotfont/)」增補並翻新的中日文像素字體。
 - 本字體目前還在**先行測試階段**，**仍缺少大量簡體漢字**。
 - 本字體**刪除了原字體漢字、假名以外的部分**，這部分字符我正在重新進行繪製。
 - 本字體除 **ASCII** 部分為半寬外，其餘字符均為全寬。

## 💡 命名靈感
> **半畝方塘一鑑開**，天光雲影共徘徊。
> 
> 問渠那得清如許？**為有源頭活水來**。
- 本字體的命名靈感來源於**朱熹**《**觀書有感二首・其一**》，呼應著原作名稱的「**Izumi（出水 / 泉）**」。
## 💬 創作故事
- 在中國，不論是大陸、港澳還是台灣，都**長期缺少**一款可免費商用的 **16px 黑體風格像素字體**。
- 想必大家都知道 GNU Unifont。它是一款幾乎支持所有文字的像素字體，其中就包括**漢字**。
### 🎮 遊戲時的偶遇
- 我從小在大陸長大，第一次瞭解 Unifont 還是小學時遊玩《Minecraft》的時候。
- 由於當時的遊戲只用到了 SC 版，其漢字以明體風格呈現，與 12pt 下的「SimSun」大差不差，所以我那時並不知道 Unifont 有中日兩個版本。
### 😞 驚訝與失望
- 直到小學畢業，我才得知：「**原來 Unifont 也有 JP 版嗎？**」
- 我有點看膩了 SC 版的明體風格漢字，便試了試 JP 版。我發現：**JP 版的漢字竟然是黑體風格的**！
- 然而，JP 版只有**日文用到的漢字**才會呈現為黑體風格，其餘**日文不會用到的字**（比如「**喵**」「**哪**」「**疙瘩**」及**大部分簡體字**）依然是明體風格。
- 之後我有在網上搜索，我發現：**幾乎所有可免費商用且支持簡中的 16px 點陣字體，全是明體風格，沒一個黑體風格的。**
- 於是乎，我下定決心，要做一款**可免費商用，且同時支持簡繁中文**的 **16px 點陣黑體**。
### 📅 五年後的嘗試
- 一開始我是看不上 Unifont JP 的，一是因為它的**非漢字部分看著有點亂**，二是因為當時 Unifont 使用的是 **GPL 許可證**，與 OFL **不兼容**。（雖然 Unifont 後來還是允許了 OFL）
- 中間也有過幾次完全從零自製，但不是方法不對就是做到一半發現很彆扭，最終**皆以失敗告終**。
- 2026 年 1 月，我在與群友聊天時，知道了 Unifont JP 的漢字部分來源於一款叫「**Izumi Gothic**」的點陣字體。
- 我看了一眼這個字體，發現其非漢字部分質量堪憂（甚至不如 Unifont），但是和之前的印象一樣，漢字質量還行，**稍微修一下就能看**。而最最重要的是——它是一款**公有領域**的字體！
- 同年暑假，我在作業之餘，下載了這個字體，提取了其內置的點陣，正式開始了這個項目。
